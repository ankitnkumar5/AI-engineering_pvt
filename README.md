# 🤖 AI Engineering Roadmap & Learning Hub

A collection of hands-on projects, code implementations, notes, and experiments covering core AI engineering concepts, LLM architectures, fine-tuning, RAG systems, and AI agent frameworks.

---

## 🎯 Focus Areas

- **Fundamentals & Core ML:** Math foundations, PyTorch, and classical machine learning.
- **Deep Learning & Transformers:** Neural networks, attention mechanisms, and vision/language models.
- **Large Language Models (LLMs):** API integrations, open-source model experimentation, and prompt engineering strategies.
- **Retrieval-Augmented Generation (RAG):** Building semantic search pipelines using vector databases and frameworks like LangChain & LlamaIndex.
- **Fine-Tuning:** Customizing LLMs using LoRA, QLoRA, and Hugging Face parameters.
- **AI Agents:** Implementing autonomous workflows with tool-calling capabilities.
- **Deployment & MLOps:** Packaging AI applications with FastAPI, Docker, and building UI demos.
